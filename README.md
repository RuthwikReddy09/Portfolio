# Ruthwik Portfolio (Starter)

A clean, animated portfolio built with **React + Vite + Tailwind + Framer Motion**.

## Run locally

1) Install Node.js (v18+ recommended)
2) Install deps:
```bash
npm install
```
3) Start dev server:
```bash
npm run dev
```
Open the URL Vite prints (usually http://localhost:5173).

## Build / preview production

```bash
npm run build
npm run preview
```

## Customize

Edit `src/data.js` (all content is centralized there).

## Contact form (optional)

Create a Formspree form and replace the `action` URL in:
`src/components/Contact.jsx`

## Deploy

- **Vercel**: import this repo, default settings work
- **Netlify**: build command `npm run build`, publish directory `dist`
